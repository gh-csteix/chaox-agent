### 密钥隔离建议（默认采用双密钥）
- **`CHAOX_SYNC_TOKEN`**：仅填写在手机 App（SX / BX / CSTEIX）中，用于设备同步与权限策略上传（服务端禁止该令牌访问 `/mcp`）。
- **`CHAOX_MCP_TOKEN`**：仅填写在 AI 客户端中，用于调用 MCP 工具（服务端禁止该令牌访问 `/sync/*` 控制面）。

### 方案 A — Cloudflare Workers + D1（推荐：免费、无需信用卡、免运维）
- 进入仓库 `cloudflare-worker/` 执行 `npm install && npx wrangler login`（打开浏览器让我完成一次 Cloudflare 登录授权）。
- 执行 `npm run setup` 自动创建 D1 数据库、应用 `../server/migrations` 表结构、生成并配置 `CHAOX_SYNC_TOKEN` 与 `CHAOX_MCP_TOKEN`、部署并校验 `/health`、`/sync/sx/status` 与 `/mcp`。
- 提示：如果我在中国大陆使用手机蜂窝网络，默认 `*.workers.dev` 域名可能受限，如我有域名可顺便指导我在 Cloudflare 后台绑定自定义子域名。

### 方案 B — 自建 Docker / Node 22.13+ SQLite（不依赖 Cloudflare）
1. **公网 VPS + 域名（Docker Compose + Caddy 自动 HTTPS）**：
   - 将域名解析到 VPS 并开放 80/443 端口；
   - 进入 `server/`，复制 `.env.example` 为 `.env`（用 `openssl rand -hex 32` 分别生成 `CHAOX_SYNC_TOKEN` 与 `CHAOX_MCP_TOKEN`），复制 `Caddyfile.example` 为 `Caddyfile` 填好域名；
   - 执行 `docker compose --profile caddy up -d --build`。
2. **Mac mini / NAS / 家用主机（Tailscale 内网或公网 HTTPS）**：
   - 进入 `server/` 执行 `docker compose up -d --build`（默认仅监听 `127.0.0.1:8787`）；
   - 执行 `tailscale serve --bg http://127.0.0.1:8787`（仅个人 Tailscale 设备可达），如需云端 AI 客户端访问则用 `tailscale funnel --bg http://127.0.0.1:8787`。
3. **容器 PaaS 平台（Fly.io / Zeabur / Railway）**：
   - 使用 `server/Dockerfile` 部署，挂载持久化卷到 `/data`，配置 `CHAOX_SYNC_TOKEN` 与 `CHAOX_MCP_TOKEN`，暴露 `8787` 端口，健康检查 `/health`。
4. **直接运行 Node.js（`>= 22.13.0`，零额外数据库依赖）**：
   - 在 `server/` 执行 `npm install && npm run build`，设置 `CHAOX_SYNC_TOKEN` 与 `CHAOX_MCP_TOKEN` 后 `npm start`，前置 Caddy / Nginx / Tailscale HTTPS 反向代理。
